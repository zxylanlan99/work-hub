一、什么是注意力
注意力机制让模型在处理序列时，动态地为不同位置分配权重，从而聚焦与当前任务最相关的信息。它最早由 Bahdanau 等（2014）提出用于机器翻译，以解决 RNN 的长程依赖瓶颈。

推荐规则维度

• 相关性：与用户学习目标/知识库匹配度
• 时效性：发布时间窗口（默认 30 天）
• 权威性：来源白名单 + 域名可信度
• 完整度：正文长度 / 是否含代码图例
• 去重：同主题已入库则降级
